How it works

One output, every screen.

The output

Most shows feed several LED screens from one media server output. The processor takes a piece of that output for each screen. The output size is the canvas everything has to fit on.

Screens

Each screen is a grid of panels. Its size in pixels is the panel's pixels times the columns and rows. Its X and Y are the pixel position of its top-left corner on the output, which is what you type into the processor.

Panels that aren't there

Switch to Take out panels and click a panel to remove it, for a stepped edge, a doorway or a wall built around a set piece. Its pixels go black on the map, and the data path arrows skip it.

Single walls

For one wall's resolution, power, circuits, ports and weight, use the LED Wall Calculator. It makes a pixel map and a test card for a single wall too.
