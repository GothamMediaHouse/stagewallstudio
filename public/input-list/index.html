Good to know

Making an input list the crew can use.

One line per channel

Give every channel its own line, stereo sources included: playback left and right are two channels. Name inputs the way they'll be written on the desk scribble strip.

Phantom power

Condenser mics, lavalier and headset capsules on a cable, and active DI boxes need 48V. Picking one from the list ticks it for you; check anything you typed yourself.

Wireless counts

The count at the top adds up the wireless channels, so the RF plan and the batteries are easy to work out. Add spares in the notes.

The stage plot

Draw it from the audience's side, with downstage at the bottom, as the venue expects. Mark power drops, so the stage manager knows where to run the circuits.

Sharing

Nothing is uploaded. The whole show is packed into the link, so copy the link to share it and keep it to edit later.
