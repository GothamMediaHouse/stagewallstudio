LED Wall Calculator

Pick a panel and the columns and rows. Get the wall's resolution, size, aspect ratio, processor ports, power, circuits, weight and viewing distance, then download a pixel map or test card at the wall's exact resolution.

  • Presets for common rental panels from ROE, Absen, INFiLED and Unilumin, or your own
  • Pixel map PNG with panel numbers and data path arrows
  • A link and a summary to paste into the spec

Pixel Map Maker

Lay out every LED screen on the set on one media server output. Drag them into place, take out panels that aren't fitted, and download the pixel map.

  • Several screens, each with its own panel
  • Panel numbers, positions and data path arrows
  • A screen list with X and Y for the processor
