FFmpeg for macOS (universal: arm64 + x86_64), LGPL build for Showcaller
=======================================================================

ffmpeg   FFmpeg 7.1.5, statically linked with libvpx 1.15.2.
         License: LGPL version 2.1 or later (built WITHOUT --enable-gpl, --enable-nonfree
         and --enable-version3; no libx264, no libx265).
         Minimum macOS 11.0. Ad-hoc signed (codesign -s -). Links only system libraries in
         /usr/lib and /System (see VERIFY.txt).
         sha256 6a734d2fcbb915f7ad1e16a754a7451eb9d53abe85693770aed151bdea84f791

Built 2026-10-28 on macOS 26.6.2 (arm64), Apple clang version 21.0.0 (clang-2100.3.34.2), macOS SDK 27.0, nasm 3.02.
The x86_64 slice was cross-compiled on Apple silicon with clang -arch x86_64.

Build and verify scripts: build.sh (run "build.sh arm64" and "build.sh x86_64"), verify.sh
Then: lipo -create build/arm64/bin/ffmpeg build/x86_64/bin/ffmpeg -output mac/ffmpeg && codesign -s - --force mac/ffmpeg

Environment for every configure: MACOSX_DEPLOYMENT_TARGET=11.0,
  CF="-arch <ARCH> -mmacosx-version-min=11.0 -isysroot <MacOSX SDK>"
  libvpx built with CFLAGS=CXXFLAGS=LDFLAGS=$CF
  ffmpeg built with PKG_CONFIG_LIBDIR=build/<ARCH>/lib/pkgconfig (only libvpx is visible to pkg-config)
